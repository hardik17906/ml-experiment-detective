# Two kinds of evidence

**Experiment retrieval** searches `notes/*.md` for useful run IDs, then reads `runs/*.json` for actual measurements. It answers what happened here. **ML knowledge retrieval** searches only `knowledge/*.md`, a small offline collection of paraphrased, attributed material. It answers what may happen in ML generally. The collections stay separate so a general explanation cannot masquerade as a measurement from our experiment.

Each knowledge file records a title, URL, topic, source type, and retrieval text. The initial sources are [PyTorch optimization](https://docs.pytorch.org/tutorials/beginner/basics/optimization_tutorial.html), [PyTorch dropout](https://docs.pytorch.org/docs/stable/generated/torch.nn.Dropout), [scikit-learn validation curves](https://scikit-learn.org/stable/modules/learning_curve.html), and Google ML Crash Course pages on [learning rates](https://developers.google.com/machine-learning/crash-course/linear-regression/hyperparameters) and [loss curves](https://developers.google.com/machine-learning/crash-course/overfitting/interpreting-loss-curves). The text is local, so the app can answer offline after the embedding model is cached.

`search_ml_knowledge(query, top_k)` ranks those five chunks with keyword and MiniLM reciprocal rank fusion. It returns source metadata with each result. `v2_answers.py` puts run measurements under **Observed experiment facts**, document content under **Relevant ML knowledge**, cautious synthesis under **Possible interpretation**, and both source types under separate headings.

For `Why might lr_01_seed3 have behaved worse than lr_005_seed3?`, `compare_experiments` measures a 4.45 percentage-point decrease in final validation accuracy and a 0.1303 increase in validation loss from the 0.05 run to the 0.1 run. A learning-rate source describes a possible mechanism: overly large steps can bounce around a minimum. The paired observations are compatible with that mechanism; they do not prove it caused the difference. Other run settings, randomness, and limited trials remain relevant.
